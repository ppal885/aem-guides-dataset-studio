## Behaviour anchors from actual RAG readback

Local source chunks use `aem_ingest_7e0f224af1_`. On other indexes retrieve the URL, not these local IDs.

- `_1`, `_3`, `_4`: Map Collection groups maps for batch publishing. Open Map Collections from Guides Home or Assets navigation, create a collection, then add maps in Edit mode. Adding a map also adds its associated presets and locales. Output enablement is a separate selection.
- `_5`, `_6`: Maps and Presets supports Modified, Preset and Language filters. Rows show map title, filename, language, preset, Baseline, modification since last publication and last-generation time. A missing Baseline is shown as a hyphen.
- `_7`, `_8`: The page lists AEM Sites, PDF including Native PDF, HTML5, EPUB, Custom and administrator-created global/folder-profile presets. A new preset is disabled by default. Individual, All presets and Folder profile presets controls enable generation choices; the two bulk controls default off. Generate Selected acts on selected maps; Generate All uses all maps with configured presets. A queued/running map or preset cannot start another generation task for that same map or preset.
- `_9`, `_10`: Configure Metadata opens Asset Metadata with every collection map selected initially. The author can narrow that selection. Updates affect selected maps; tag append preserves existing tags. Document State choices must be allowed for every selected map. Updated metadata is reflected in the Editor's File Properties panel.
- `_11`: Remove From Collection removes the map's collection membership together with its preset/locale membership. Deleting a collection is a different action. Cancellation is available on a task in the collection's Outputs tab through Cancel This Job.

## Preserve boundaries when investigating a ticket

- Automatic preset/locale association does not mean automatic enablement. Do not merge these with the separately documented New Map Collection workflow merely because retrieval returns both pages.
- Filtered table contents do not establish whether Generate All obeys an active filter. Retrieve current implementation/product evidence if that question matters.
- Collection removal is not evidence for repository-asset deletion. The page describes membership removal, not every deletion side effect or retention guarantee.
- The concurrency note does not specify lock implementation, cross-user/cross-collection scope, exact error text or atomic rollback. Cancellation does not establish cleanup timing or identical behaviour across all publishing entry points.
- The prose says Append while the screenshot says Append mode. It mentions Save & Close and Submit; verify the current interaction rather than inventing an exact save sequence.
- Document State uses the common allowed choices, not the union of choices from individual maps. The page does not define an error or fallback when none are common.
- Do not infer scale limits, performance guarantees, deployment/version parity or a complete output-engine matrix.

Select relevant investigation questions; never turn the entire reference into mandatory ACs. Current Jira scope and verified implementation decide applicability.
